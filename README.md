# رفيق | Rafeeq MVP

نموذج واجهة متكامل لمنظومة رفيق الصحية، مبني بـ Next.js وTypeScript. الواجهة عربية RTL ومتجاوبة، وتضم تجارب منفصلة للحاج والطواقم الطبية وغرفة العمليات.

## التشغيل المحلي

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## المسارات الرئيسية

- `/` الصفحة التعريفية ومحدد الأدوار.
- `/app` تجربة الحاج، مع الصحة والرحلة والموقع والمساعد والسوار والملف الطبي.
- `/medical` لوحة الطاقم الطبي والحالات وصفحة الحالة الكاملة.
- `/operations` مركز العمليات والمناطق وتفاصيل المخاطر المجمعة.

## قاعدة البيانات

إعدادات PostgreSQL الخادمية محفوظة في `.env.local` وغير مضمنة في المستودع. استخدم `.env.example` لمعرفة أسماء المتغيرات المطلوبة. يفحص المسار `/api/system/database` الاتصال من الخادم فقط، ولا يرسل بيانات الاعتماد إلى المتصفح.

عندما لا يكون الخادم متاحًا، يعمل النموذج تلقائيًا بطبقة البيانات التجريبية المركزية في `lib/mock-data.ts` حتى تبقى جميع تدفقات العرض قابلة للاستخدام.

بعد فتح اتصال PostgreSQL، أنشئ الجداول وأدخل بيانات العرض بالأمر التالي من جذر المشروع:

```bash
npm run db:init
```

الملف `db/init.sql` آمن لإعادة التشغيل: ينشئ الجداول عند غيابها ويحدّث بيانات العرض بدل تكرارها.
